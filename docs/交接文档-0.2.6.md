## 3. 0.2.6 交付内容（按模块）

### 3.1 页面标注（核心）
- 入口：`Ctrl+Shift+A` / 工具栏「✎ 标注」/ `⋯`→页面标注；工具 1-4（框/圈/箭头/点选）
- **投递路由（按面板模式）**：内置模型 → 直投 AgentRuntime（有提问触发回答）；opencode → 注入队列（未连接给 warning）；**外部工具（Codex/Claude）→ 投递进当前打开的会话**（复用面板续聊通道；无可用会话时给明确指引）
- 回执（成功/失败/排队 warning）、marker 文档坐标跟随滚动、退出清空、未提交保留可重开、箭头最小豁免、shadow DOM 采样
- **覆盖版修复（必读）**：页面每次加载（overlay `ready`）时，主进程会把该标签的标注状态**同步重置为关闭**——这是为了修复"导航后首击 ✎ 无反应"的失步 bug（历史坑，勿删此逻辑）

### 3.2 AI 面板
- 三种模式：内置模型（默认）/ opencode 双向镜像 / 外部 CLI（Codex/Claude/Gemini/Qwen/自定义）
- 草稿按模式持久化、IME 防误发、失败保留草稿、停止清队列、60 步上限提示、错误中文归因、权限卡显示内容预览 + Esc 拒绝

### 3.3 安全 / 数据
- 导入凭据白名单（`shared/trusted-hosts.ts`）；自定义网关需勾选「我信任此网关」
- settings / browser-data / agent store 原子写 + `.bak` 回退；调试端点 `app.isPackaged` 门控
- 下载前询问（默认开，`⋯` 菜单可关）；浏览数据损坏留档

### 3.4 浏览器功能
- 标签：中键关 / 双击新建 / 溢出滚动 / 右键原生菜单（复制、关闭其他/右侧、重新打开、**最近关闭列表 ≤10**、**静音**、**所有标签存书签**）
- 页面：`Alt+←/→`、`Ctrl+±/0`、查找条（文档流 + 计数 + 上/下）、**页面右键原生菜单**、**复制为 Markdown**
- 键盘：**16 个动作全部可自定义**（见 §5.1）

### 3.5 书签（完整管理）
文件夹增删改 · 书签增改删 · 新标签打开（Ctrl/中键）· 复制链接 · 排序（最近/A–Z）· 搜索 · 数量徽标

### 3.6 CLI 网页路由（FB-001，覆盖版新增）
- **候选浏览器注册**（`main/browser-registration.ts`）：Windows HKCU 写 `DuplexURL`/`DuplexHTML` ProgID + `RegisteredApplications` + `Capabilities`；**仅打包版执行、只写 HKCU、绝不改默认**；启动 3 秒后异步执行、已注册则跳过；`⋯ → 设为默认浏览器…` 打开系统设置页
- **BROWSER 垫片**（`main/open-shim.ts`）：生成 `~/.cobrowse/shims/duplex-open(.cmd/.js)`，读端点调 `POST /api/open`；**面板发起的外部 CLI、内置模型的 `run_command` 与脚本执行**都注入 `BROWSER=duplex-open` 并把垫片目录置于 PATH 首位
- **URL 入口**：命令行参数 / `second-instance` / macOS `open-url` 都会在 Duplex 新标签打开

### 3.7 发布工程
- CI（`.github/workflows/build.yml`）：推送 `v*` 标签 → 三平台构建 → 自动建/更新 Release（`--clobber`）→ **强制发布**（`40cad45` 起）
- 覆盖发布流程、SHA256 与资产清单见 §7

### 关键机制（改代码前必读）
1. **契约三件套**：新增 IPC 必须同步改 `preload/index.ts` + `renderer/src/env.d.ts`（+ 主进程 handler）。
2. **面板模式决定标注去向**：渲染层通过 `setPanelMode(mode)` 上报；主进程 `currentPanelMode` 决定 deliver 路由（agent / external 会话 / mirror）。
3. **标注状态同步规则**：主进程 `annotationTabState` 与页面覆盖层必须一致；覆盖层每次加载会发 `ready`，主进程借此重置该标签状态——**任何改动不要绕过这条同步**。
4. **两套键位系统**：快捷键（16 动作，`shared/shortcuts.ts`）与急停键（`settings.emergencyStopKeys`）相互校验冲突；`BUILTIN_SHORTCUTS` 是急停键的静态保留表。
5. **调试接口**：`COBROWSE_DEBUG_UI=1` + 非打包构建才可用；打包版返回 404。
6. **单例锁**：dev 与安装版共用 userData 会互斥；并行调试用 `--user-data-dir`。
7. **FB-001 三件套**：候选注册（仅打包版）+ 子进程 `BROWSER` 垫片 + URL 入口；改动 `spawn` 处记得带上 `duplexShimEnv(ensureOpenShim())`。

## 5. 扩展 recipe（高频改动照着做）

### 5.1 新增一个可自定义快捷键动作
1. `shared/shortcuts.ts`：`ShortcutAction` 加 id、`SHORTCUT_DEFS` 加中文标签、`DEFAULT_SHORTCUTS` 加默认组合。
2. `main/tabs.ts` `before-input-event`：动作分发加 case（页面内生效）。
3. `renderer/App.tsx`：动态匹配的 action 分发加 case（chrome 焦点生效）。
4. 如需新行为：`main/index.ts` 的 `onShortcut` 转发或 `tabs:action` 增加处理。
5. 冲突校验自动生效；补 `tests/shortcuts.test.ts` 用例。

### 5.2 新增一个 IPC 通道
1. `preload/index.ts` 暴露方法（invoke/send/on）。
2. `renderer/src/env.d.ts` 同步类型。
3. `main/index.ts` 加 handler（写操作走 `settings.save*` 并返回 `{ok,error}`）。
4. 需要广播就 `win.webContents.send('xxx:changed', …)`。

### 5.3 新增一个设置项
`main/settings.ts`：接口 + cache 默认值 + 加载消毒 + `saveXxx(): SaveResult`（原子写自动复用）→ IPC → UI 消费（失败 toast：`window.dispatchEvent(new CustomEvent('duplex:toast',{detail}))`）。

### 5.4 修改标注投递规则
`main/index.ts` 的 `deliverAnnotation`（按 `currentPanelMode` 路由）+ `annotations.ts` 的 deliver 契约；外部模式投递走 `sendToCurrentExternalSession`（与面板续聊同一函数）。回执结构见 `overlay.ts` 的 `annotationResult`（ok/error/warning/elementCount）。

### 5.5 新增一个"URL 打开"入口或垫片行为
`main/open-shim.ts`（`extractHttpUrl` / `ensureOpenShim` / `duplexShimEnv`）+ `http-server.ts` 的 `POST /api/open`；主进程入口在 `start()`（启动参数）与 `second-instance` / `open-url` 事件。补 `tests/open-shim.test.ts` 用例。

### 已知坑与限制
- **删除 git 标签会把 Release 变草稿**（已踩过；CI 已加固为"上传后强制发布"）。
- **native 菜单无法自动化验证**：标签右键/页面右键/搜索引擎/⋯ 菜单是 OS 级弹窗；建议手点一遍。
- **opencode 插件会抢注入队列**：带 `/api/chat` 的测试消息会被投递进外部 opencode 会话；`inject-latency` 已改 opt-in（`INJECT_LATENCY=1` 且无其他消费者时再跑）。
- **smoke 的标注断言依赖面板模式**：已通过 dev-only `POST /api/debug/ui-action {action:'panel-mode:opencode'}` 固定；无调试接口时该项可能因用户配置差异失败。
- **`/api/debug/exec` 不支持顶层 return**：脚本用表达式形式，如 `(async () => { … })()`。
- **标注在内部滚动容器站点**（Gmail/ChatGPT 类）可能滚不动：待实机复现后修 overlay 滚轮穿透。
- **macOS 窗口重建**：`app.on('activate')` 会重建窗口/TabManager，但 http-server/agent 启动时捕获的旧 tabs 引用不会自动重绑（已知边界）。
- **example.com 无 `<h1>`**：smoke 已改查 `p`（勿改回去）；备选测试页见 §7。
- **忽略 `$BROWSER` 的工具**（如 Claude Code 用的 node-open）：需要用户在系统设置把 Duplex 选为默认（提供一键入口，不强制）。
