## 4. 代码地图

```
src/
├─ shared/           主/渲染/桥共享
│  ├─ protocol.ts         IPC 事件与数据类型（TabInfo/MirrorEvent/BookmarkRecord/BrowserDataSnapshot…）
│  ├─ shortcuts.ts        快捷键动作注册表 + 默认值 + 校验（16 动作）
│  ├─ hotkeys.ts          按键解析/匹配/显示（含 Mac ⌘ 等价）
│  ├─ trusted-hosts.ts    导入凭据官方域名白名单
│  └─ tools.ts            MCP 工具定义（24 个）
├─ main/
│  ├─ index.ts            总装配：窗口/IPC/菜单/标注路由/急停/外部进程
│  ├─ tabs.ts             WebContentsView 标签管理、页面内快捷键、菜单事件、静音/最近关闭
│  ├─ settings.ts         设置持久化（原子写+.bak；含 shortcuts 覆盖）
│  ├─ browser-data.ts     书签/历史/下载存储（书签文件夹 API）
│  ├─ mirror.ts           opencode 镜像事件流 + 注入队列（touchConsumer/hasConsumer）
│  ├─ annotations.ts      标注采样→结构化文本→deliver 回调
│  ├─ overlay.ts          页面覆盖层命令 + 急停状态机（paused 持久化）
│  ├─ http-server.ts      本地 HTTP/MCP 服务 + 调试路由（isPackaged 门控）
│  ├─ agent/              内置模型 agent（runtime/providers/skills/fs-tools/llm/*）
│  └─ integrations/       外部 CLI（agents/transcripts/setup）
├─ preload/index.ts       contextBridge API（**契约源**）
├─ renderer/src/          React（App.tsx 外壳 + components/* + styles.css + env.d.ts）
├─ overlay-preload/       页内标注/可视化（独立 preload）
└─ mcp-bridge/            stdio MCP bridge（外部 CLI 接入）
```

### 关键机制（改代码前必读）
1. **契约三件套**：新增 IPC 必须同步改 `preload/index.ts` + `renderer/src/env.d.ts`（+ 主进程 handler）。
2. **面板模式决定标注去向**：渲染层通过 `setPanelMode(mode)` 上报；主进程 `currentPanelMode` 决定 deliver 路由（内置=AgentRuntime / 其他=mirror）。
3. **两套键位系统**：快捷键（16 动作，可改，`shared/shortcuts.ts`）与急停键（最多 5 个，`settings.emergencyStopKeys`）**相互校验冲突**；`BUILTIN_SHORTCUTS` 是急停键的静态保留表。
4. **调试接口**：`COBROWSE_DEBUG_UI=1` + 非打包构建才可用；打包版返回 404。
5. **单例锁**：dev 与安装版共用 userData 会互斥；并行调试用 `--user-data-dir`。

## 5. 扩展 recipe（高频改动照着做）

### 5.1 新增一个可自定义快捷键动作
1. `shared/shortcuts.ts`：`ShortcutAction` 加 id、`SHORTCUT_DEFS` 加中文标签、`DEFAULT_SHORTCUTS` 加默认组合。
2. `main/tabs.ts` `before-input-event`：在动作分发处加 case（页面内生效）。
3. `renderer/App.tsx`：动态匹配的 action 分发加 case（chrome 焦点生效）。
4. 如需新行为：`main/index.ts` 的 `onShortcut` 转发或 `tabs:action` 增加处理。
5. 冲突校验自动生效；补 `tests/shortcuts.test.ts` 用例。

### 5.2 新增一个 IPC 通道
1. `preload/index.ts` 暴露方法（invoke/send/on）。
2. `renderer/src/env.d.ts` 同步类型。
3. `main/index.ts` 加 handler（写操作走 `settings.save*` 并返回 `{ok,error}`）。
4. 需要广播就 `win.webContents.send('xxx:changed', …)`。

### 5.3 新增一个设置项
`main/settings.ts`：接口 + cache 默认值 + 加载消毒 + `saveXxx(): SaveResult`（原子写自动复用）→ IPC → UI 消费（失败时 toast：`window.dispatchEvent(new CustomEvent('duplex:toast',{detail}))`）。

### 5.4 修改标注投递规则
`main/index.ts` 的 `deliverAnnotation`（按 `currentPanelMode` 路由）+ `annotations.ts` 的 deliver 契约；回执结构见 `overlay.ts` 的 `annotationResult`（ok/error/warning/elementCount）。

## 6. 待办 / 已知问题（重要）

### backlog（调研产出，未实现）
命令面板（统一搜标签/书签/历史/动作）· 标签搜索 · 会话快照恢复 · 阅读模式 · Glance 悬浮预览 · 标签固定 · 多选批量管理 · 书签 HTML 导入/导出 · token/费用统计 · 响应式适配 · 触屏标注 · 模型「测试连接」按钮 · 新会话工作目录选择器。

### 已知坑与限制
- **native 菜单无法自动化验证**：标签右键/页面右键/搜索引擎/⋯ 菜单是 OS 级弹窗，测试无法点选；建议手点一遍（自动化会卡住）。
- **opencode 插件会抢注入队列**：跑带 `/api/chat` 的测试时消息会被投递进外部 opencode 会话；`inject-latency` 已改 opt-in（`INJECT_LATENCY=1` 且无其他消费者时再跑）。
- **smoke 的标注断言依赖面板模式**：已通过 dev-only `POST /api/debug/ui-action {action:'panel-mode:opencode'}` 固定；无调试接口时该项可能因用户配置差异失败。
- **`/api/debug/exec` 不支持顶层 return**：脚本用表达式形式，如 `(async () => { … })()`。
- **标注在内部滚动容器站点**（Gmail/ChatGPT 类）可能滚不动：机制上待修（overlay 图层截获 wheel），需实机复现后处理。
- **macOS 窗口重建**：`app.on('activate')` 会重建窗口/TabManager，但 http-server/agent 启动时捕获的旧 tabs 引用不会自动重绑（已知边界）。
- **example.com 无 `<h1>`**：smoke 已改为查 `p`（勿改回去）。
