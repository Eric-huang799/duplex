# Duplex 0.3.0-beta.2（多 agent 调试版 · **不稳定**）

> **不要把这个版本当作日常浏览器。** 多 agent 能力仍在调试，行为会变、边角会崩、界面还没做完。
> 日常可用版本仍是 **v0.2.10**。欢迎反馈 issue 与可复现的失败。

## 这一版把多 agent 合进了主线

| 能力 | 说明 |
| --- | --- |
| 身份隔离 | 外部 agent 身份 `bridge:<安装>-<工作目录>`；内置会话 `builtin:<sessionId>`，互不共用授权与 ref |
| 仲裁 | 导航屏障（等，超时才抢占）、被抢占的调用**硬失败**、同一目标按编号加权串行 |
| 授权 | 按 `(actor, origin)`，A 同意过的站点 B 仍要单独问；旧 v1 授权丢弃并写日志 |
| ref 命名空间 | `a<actor>:e12` + 快照指纹，元素被别人改过就作废；页面内零新增属性 |
| 并行内置会话 | 每个会话一个 runtime，工具计数与事件按会话归属；头部显示 `⚡N` |
| 验收入口 | 预置任务面板「⚡ 并行演示：两个 agent 同时操作」 |

## 实测数字

- 导航屏障：等 404ms，对方 5 次点击全部落地
- 强制抢占：第 3 步被拦，回退后补做 5 次（总 8 = 计划 8）
- 三 agent 抢同一按钮：点击 3 次、最大并发 1、顺序按编号
- 两个真模型同标签：7.1s 内 20 次工具调用，2 次点击 + `duplex`
- 耦合任务（两个加数）：submits=1、a=6、b=7、sum=13
- 并行内置会话：7.1s，12 + 8 次工具调用，最终状态正确

## 修掉的问题

- 权限实例分叉（恢复还原点后判权用旧实例、旧快照覆盖新规则）
- 挑战页拿不到 iframe/正文（登录页内嵌 reCAPTCHA 不再漏判）
- 站点闸门按未解析 URL 判定（`mail.google.com` 不再绕过授权）
- 导出脱敏漏 `Cookie` / `Authorization` / 正文 `x-api-key`
- `run_command` 在 `start`/`Start-Process` 起的后台服务上卡死整轮（新增长时间无输出看门狗 + detached 快路径）
- ref 命名空间里出现第二个冒号（`abuiltin:demo-a:e12` → `abuiltin-demo-a:e12`）
- CI：预发布 tag 不再被强标 latest 而失败

## 已知边界

1. 后台会话没有独立历史面板（只有徽标与计数）
2. iframe 内元素没有命名空间/指纹
3. 动态文本或位移 >2px 会让旧 ref 作废（宁可报错不点错）
4. `agentMayBrowseUnlisted` 仍为 true：未授权的**非敏感**普通站点照旧放行
5. `run_command`/curl 不走站点授权表
6. 一直有输出但永不退出的命令仍会等到 timeout（建议重定向输出）

完整分析见 `docs/multi-agent-shared-tab.md`。
