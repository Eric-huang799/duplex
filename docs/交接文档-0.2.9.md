## 人机协作行为

| 人的行为 | AI 的行为 |
| --- | --- |
| 持续滚轮或触摸滑动 | 继续读取；普通元素点击与标准 input/textarea 输入采用 DOM 操作，保留当前焦点与阅读位置；AI 主动滚动不改变人的位置 |
| 滚动期间要求悬停、拖拽、按键或输入后 Enter 提交 | 返回需要协调的原因，继续观察与推理，不循环等待人停止滚动 |
| 点击、输入或触摸点按任务页 | 该标签的修改操作暂停，读取继续；顶部提供逐页恢复 |
| 导航、刷新或开启标注 | 停止该页正在执行的修改，要求重新观察与恢复；标注结束本身不自动恢复 |
| 切换可见标签 | AI 继续使用原任务标签 |
| 关闭任务标签 | 后续调用明确报标签已关闭；不会改为操作新活动页 |
| 停止内置任务 | 取消该任务的模型、工具及待确认操作，等待实际工具结束，再接受替换指令 |
| 急停 | 取消全部当前操作与本应用启动的 CLI 子进程，清除待投和已领取注入；后台重排、续租和确认不会恢复 AI |

滚动保护使用轮滚/触摸事件，不把页面自动滚动当成人工接管。触摸移动与点按在结束时区分。AI 输入只在实际执行阶段标记，组合按键包括修饰键；等待元素时仍观察人工输入。

## 实现入口

- `src/main/playwright-browser.ts`：通过 Electron `DevToolsActivePort` 连接现有 Chromium，以 targetId 对应标签；定位、动作、iframe/open shadow、截图、等待和脚本执行。
- `src/main/collaboration.ts`：调用方与任务标签绑定、同页修改串行、人工接管与恢复。内置任务开始时捕获标签，排队消息保存提交时的标签；MCP bridge 携带固定调用方 ID。
- `src/main/interrupt.ts`、`agent/runtime.ts`：区分普通停止、逐页接管和全局急停；切会话删除旧自动发送；无问题的标注在模型请求边界加入上下文。
- `src/main/page-scripts.ts`：引用编号不复用，保留最近三份快照；动作检查元素是否连接及内容是否变化。
- `src/main/annotations.ts`、`index.ts`：标注捕获来源标签、URL、文档标识和接收会话；采样前后检查导航与取消，拒绝过期标注。
- `src/main/mirror.ts`、`session-bus.ts`、OpenCode 插件：单条领取、按目标会话/消费者分配、60 秒租期、每 20 秒续租、原 ID 重排与 ACK；急停后旧领取失效。插件两份副本保持一致。
- `src/main/integrations/session-events.ts`：读取 Codex/Claude 的结构化启动身份，用对应元数据匹配新会话；不使用“最近更新的文件”判断启动对象。
- `src/main/browser-session.ts`：退出时保存页面顺序、HTTP(S) URL 和活动页面，启动时恢复；空白页可恢复，file/data 页面不持久化。
- renderer/preload：地址编辑与错误重试绑定来源标签、输入法确认不提交地址、确认卡不抢焦点、外部状态由主进程同步、支持暂停后修改指令。

## 已知边界与 0.3.0 工作

1. 滚动期间的 DOM 点击/输入事件为 `isTrusted=false`。依赖真实键鼠、contenteditable 或页面自定义控件需要协调；页面业务处理程序自己的导航、焦点与滚动副作用不能通用撤销。
2. Playwright locator 没有本项目使用的 AbortSignal 接口。在途动作以 200–250ms 超时限制，并等待实际调用结束；已经发生的点击、提交或写入不能回滚。后续应把观察、准备和输入执行拆为明确的可取消步骤。
3. `evaluate` 清理其作用域内的计时器、RAF 和 fetch，并终止同步执行；通过 `document.defaultView` 等途径注册的外部回调不能保证撤销。0.3.0 应进一步限制此高级能力的使用范围。
4. MCP 调用方在 bridge 生命周期内固定；修改所有者需任务结束释放或用户显式交接。没有自带身份的直接 MCP 客户端共用默认身份。0.3.0 应提供明确的任务开始、结束和恢复协议。
5. OpenCode 持续网络失联超过租期时，已接受但未确认的消息可能重复投递；精确去重需上游支持消息 ID。已被上游接受的执行也不能仅靠清空本地队列撤销。
6. Codex/Claude 按结构化 ID 匹配。自定义 CLI 缺少启动身份时，只接受唯一新文件；同时有多个候选会拒绝选择。更丰富的 CLI 会话生命周期与通用取消留待 0.3.0。
7. 本轮未调用付费模型或真实 CLI 会话。内置多模态图片上下文、各网站特殊控件和跨浏览器平台的交互验收需要单独推进。

## 本地开发

最终类型检查通过，单元测试 303 通过、1 跳过，应用与 bridge 构建通过；11 个主进程协作场景分轮实测通过，独立页面冒烟通过。没有运行真实模型/CLI任务；使用边界与临时数据保留情况见开发日志。

```powershell
npm run typecheck
npm test
npm run build
npm run build:bridge
node tests/playwright-connection-smoke.mjs
node tests/private-029-smoke.mjs
```

两个冒烟脚本使用隐藏 Electron 与独立临时数据目录，本地 fixture 不涉及用户会话。若当前 Windows shell 的 PATH 超过 cmd 的长度限制，先在该 shell 中缩短 PATH；不修改系统环境变量。对应诊断与检查结果记录在开发日志。

本地体验可用 `npm start`；并行运行旧安装版时设置 `DUPLEX_DATA_DIR` 到另一个目录，避免争用现有配置和 endpoint。构建产物位于 `out/` 与 `dist-bridge/`，不在 Git 中保存。
