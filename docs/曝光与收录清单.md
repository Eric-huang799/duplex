## 二、下一步（按优先级）

### P0-1 · 发布 npm 包 + 官方 MCP Registry（解锁下游一切）
浏览器操作（已完成）：`npm/duplex-bridge/` 发布包就绪（name `duplex-bridge`，bin、`mcpName: io.github.eric-huang799/duplex`）；`src/mcp-bridge/index.ts` 已支持"无项目根"的 npm 场景（优先拉起已安装的 Duplex）。

**需要作者本人执行**：
```powershell
# 1) 发布 npm 包
cd npm\duplex-bridge
npm login          # 你的 npm 账号（当前 duplex-bridge 等名字均未被占用，建议尽快占名）
npm publish --access public

# 2) 安装官方 Publisher 并发布到 Registry
$arch = if ([System.Runtime.InteropServices.RuntimeInformation]::ProcessArchitecture -eq "Arm64") { "arm64" } else { "amd64" }
Invoke-WebRequest -Uri "https://github.com/modelcontextprotocol/registry/releases/latest/download/mcp-publisher_windows_$arch.tar.gz" -OutFile "mcp-publisher.tar.gz"
tar xf mcp-publisher.tar.gz mcp-publisher.exe
.\mcp-publisher.exe init        # 核对 server.json：name=io.github.eric-huang799/duplex、transport=stdio、identifier=duplex-bridge、描述 ≤100 字符
.\mcp-publisher.exe login github
.\mcp-publisher.exe publish
```
验证：`curl "https://registry.modelcontextprotocol.io/v0.1/servers?search=io.github.eric-huang799/duplex"`

> 意义：PulseMCP（现暂停收件）恢复后**自动抓取官方 Registry**；GitHub/VS Code 画廊与多数目录表单都以 Registry 为源头。
