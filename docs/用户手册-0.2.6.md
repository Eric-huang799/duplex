# Duplex 0.2.6 操作手册（完整操作清单）

> 版本：0.2.6（本地开发版）｜生成：2026-10-07
> 说明：本文覆盖每一个用户可执行的操作、用法与效果。

---

## 0. 快速上手（首个 5 分钟）

1. 打开 Duplex：起始页可直接输入搜索词，或点地址栏输入网址。
2. 用 AI：点右上角 **AI** 按钮展开面板 → 顶栏选 **内置模型** → 点 **⚙** 配置模型（有 DeepSeek / OpenAI / 本地 Ollama 一键预置）→ 保存 → 底部输入框发消息。
3. 三个必记操作：`Ctrl+Shift+A` 页面标注、`Ctrl+B` 开关 AI 面板、急停键（新装默认 `F2`）；想改键：`⋯` → 快捷键设置。

## 1. 浏览器基础操作

| 操作 | 方法 | 效果 |
|---|---|---|
| 新建标签 | 标签栏 `+` / **双击标签栏空白** / `Ctrl+T` | 打开新标签页，光标自动聚焦地址栏 |

| 恢复关闭的标签 | `Ctrl+Shift+T` 或标签右键菜单 | 重新打开最近关闭的页面 |
| 标签右键菜单 | 右键任意标签（**原生菜单**） | 复制标签页（同网址新开）/ 关闭其他 / 关闭右侧 / 重新打开关闭的标签页 |
| 标签溢出 | 标签多时自动横向滚动，滚轮横滚 | 活动标签自动滚入可视区 |
| 输入网址/搜索 | 地址栏输入后回车 | 网址直开；普通词自动用当前搜索引擎搜索 |
| 聚焦地址栏 | `Ctrl+L` | 全选当前网址，直接输入替换 |
| 前进 / 后退 | 工具栏箭头 / `Alt+←`、`Alt+→` | 页面导航（地址栏聚焦时同样生效） |
| 刷新 / 停止 | 刷新按钮；**加载中按钮变 ✕** / `Ctrl+R` | 加载中点击即停止加载 |
| 页面内查找 | `Ctrl+F` | 页面上方出现查找条（不遮挡网页），实时高亮 + 匹配计数；`Enter` 下一个、`Shift+Enter` 上一个、`↑/↓` 按钮、`Esc` 关闭并清除高亮 |
| 页面缩放 | `Ctrl+=` 放大 / `Ctrl+-` 缩小 / `Ctrl+0` 重置 | 按 0.5 级调整，范围 ±5 级 |
| 书签 | 星标按钮 或 `Ctrl+D` | 添加/移除当前页书签；书签面板可完整管理（文件夹/编辑/删除/新标签打开/排序，见 §3.5） |

| 下载 | `⋯` 菜单 → 下载内容 | 进行中可取消；清空只清记录**不删文件**；打开/在文件夹显示（文件丢失会提示）；完成/中断弹出 toast |
| 下载前询问 | `⋯` 菜单勾选「下载前询问保存位置」（默认开） | 开启时每个下载弹系统保存框；关闭则直接存到系统下载目录 |
| 页面右键菜单 | 网页内右键 | 链接（新标签打开/复制地址）、图片（新标签打开/复制地址/另存为）、选中文字（复制/用当前引擎搜索）、输入框（剪切/复制/粘贴/全选）、通用（前进/后退/刷新/复制页面地址/复制为 Markdown） |
| 标签静音 | 标签上的 🔇/🔊 图标，或标签右键菜单 | 一键静音/取消；有声与静音状态直接显示在标签上 |

| 全部标签页存书签 | 标签右键 → 所有标签页加入书签 | 自动创建「标签组 月-日 时:分」文件夹并保存所有网页标签 |

| 搜索引擎 | 地址栏右侧「百度 ⌄」**原生菜单** 或起始页 | 切换后地址栏搜索与起始页搜索同步生效 |
| 起始页 | 无页面时 | 大搜索框 + 常用书签 + 最近历史，点击直达 |
| 加载失败 | — | 顶部 toast「页面加载失败：原因（网址）」+ 重试按钮 |

## 2. 快捷键（可自定义）

**改键方法**：`⋯` 菜单 → **快捷键设置**。点某动作的「录制」后直接按下新键（`Esc` 取消录制）；单动作「恢复默认」或底部「恢复全部默认」；「保存」后**立即生效**（地址栏焦点与网页内都生效）。非法组合、动作间重复、与急停键冲突都会被拒绝并给出中文提示。`Ctrl+1`…`Ctrl+9`（切标签）为系统保留，不可改。

下表为默认值（可在上面随时改）：

| 快捷键 | 功能 |
|---|---|
| `Ctrl+L` | 聚焦/全选地址栏 |
| `Ctrl+T` / `Ctrl+Shift+T` | 新建标签（聚焦地址栏）/ 恢复关闭的标签 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+R` | 刷新 |
| `Ctrl+D` | 添加/移除书签 |
| `Ctrl+F` | 查找（Enter 下一个，Shift+Enter 上一个） |
| `Ctrl+B` | 开关 AI 面板 |
| `Ctrl+Shift+A` | 进入/退出页面标注 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个/上一个标签 |
| `Ctrl+1`…`Ctrl+9` | 第 1…8 个标签 / 最后一个标签（保留键） |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 重置缩放 |
| `Alt+←` / `Alt+→` | 后退 / 前进 |
| `1`–`4`（仅标注模式） | 框选 / 圈选 / 箭头 / 点选 |
| 急停键（可自定义，默认 `F2`、`Ctrl+Shift+K`） | 立即急停（见 §5） |
| `F12`（仅开发版） | 开发者工具 |

## 3. 页面标注（Duplex 核心功能）

**怎么进：** 工具栏「✎ 标注」按钮 / `Ctrl+Shift+A` / `⋯` 菜单「页面标注」。空白页不可用（按钮置灰）。页面内焦点同样生效。

**怎么用：**

| 步骤 | 操作 | 效果 |
|---|---|---|
| 选工具 | `1` 框选 / `2` 圈选 / `3` 箭头 / `4` 点选，或点工具条按钮 | 工具条可拖动（不挡内容） |
| 画标注 | 在页面上拖拽/点击 | 出现标注框；自动弹出提问卡 |
| 提问 | 输入问题后 `Enter` 发送；`Esc` 收起卡片（标注保留为虚线，点它可继续编辑） | 未提问直接发送也可（见下方送达规则） |
| 删除单条 | 标注上的 `×` | 只删这一条 |
| 清空全部 | 工具条 🗑 | 清除全部标注 |
| 退出 | 再按 `Ctrl+Shift+A` / 工具条 `✕` | 退出标注模式；若有未提交的虚线标注会提示「已退出，N 个未提交标注已清除」 |

**发送后你会看到：** 页面底部状态条显示「已发送给 AI（N 个元素）」；失败或排队会出示原因。标注内容是结构化文本（页面 URL、框内元素、CSS 选择器、可见文本、可交互元素清单），AI 还能用 query / get_html 复查。

**送达规则（跟随面板当前模式）：**

| 面板模式 | 结果 |
|---|---|
| 内置模型 | 有提问 → 直接触发 AI 回答；无提问 → 只记录进对话（提示"未提问，AI 不会单独回应"） |
| opencode | 进入注入队列；opencode 未连接时提示「已排队，连接后自动送达」 |
| 外部工具（Codex/Claude 等） | **拒绝并提示**切换模式（外部 CLI 收不到标注） |

### 3.5 书签面板（`⋯` → 书签）

- **文件夹**：顶部文件夹栏含「全部」「未分类」与自建文件夹（带数量）；「＋ 新建文件夹」；双击文件夹改名（Enter 确认 / Esc 取消）；`×` 删除（两步确认，夹内书签自动移回未分类）。
- **新建**：右上「＋ 新建书签」→ 填标题（可留空，默认用网址）、网址、所属文件夹。
- **管理每一条**：悬停出现操作——打开（当前标签）、在新标签打开、编辑（行内改标题/网址/文件夹）、删除（两步确认）、复制链接；行点击=当前标签打开，`Ctrl/⌘+点击` 或**中键**=新标签打开。
- **搜索与排序**：顶部搜索框实时过滤；「排序: 最近添加 / 标题 A–Z」一键切换。
- 数据自动原子写盘 + `.bak` 备份。

## 4. AI 面板（三种模式）

面板顶部模式栏：**内置模型** 按钮 ＋ 工具下拉（`opencode（双向镜像）` / 检测到的外部工具 / `＋ 添加自定义工具…`）。

### 4.1 内置模型（默认）
- 直接调用你配置的 API 模型操作浏览器。首次无配置时自动弹配置面板。
- **发送**：底部输入框，`Enter` 发送 / `Shift+Enter` 换行；中文输入法回车确认候选不会误发。
- **运行中**：状态「内置模型工作中…」，可继续输入——消息排队，任务完成后自动发送（只显示一条气泡）；点 **停止** 立即中断并**清空排队消息**（提示取消条数）。
- **单轮 60 步上限**：达到后 AI 会说明「任务可能未完成，可继续发消息接着做」。
- **草稿**：输入未发送时收起面板/切换模式都不丢（按模式分别保存）。
- **顶栏**：`⚙` 模型配置（§7）、`✦` Skills 与 CLI 接入（§8）、`☰` 历史对话（新建 / 切换 / 删除——删除需连续确认；AI 运行中切换会被拒绝并提示）。
- **错误提示**：条带显示中文归因（Key 无效 / 限流 / 超时 / 网络），可立即关闭；超时可在模型配置里调大"空闲超时"。

### 4.2 opencode（双向镜像）
- 监听本地 opencode 会话：opencode 里的对话实时镜像到面板，面板输入的消息注入 opencode。
- `☰` 选择连接的对话（自动跟随 / 指定 / 新建）。
- opencode 未连接时发消息：提示「opencode 未连接：消息已排队，连接后自动送达」。

### 4.3 外部工具（Codex / Claude / Gemini / Qwen / 自定义）
- 下拉选择工具（未安装会标「未检测到」）。
- **输入第一条消息**：以无头模式启动该 CLI 新会话（显示在面板）。
- **打开历史会话**（☰）后可**续聊**（Codex / Claude 支持面板回复；其他工具为只读镜像，去 CLI 里继续）。
- **模型行**（Codex / Claude）：查看/切换模型；「写入全局配置」会改动该 CLI 的全局配置（影响所有终端会话）——有二次确认并自动备份。
- **停止**：终止由面板发起的外部进程。
- 会话记录同步中断时，面板顶部出现横幅提示，重新打开会话即可恢复。

### 4.4 权限确认卡（AI 要执行敏感操作时）
- `write_file`（写文件）、`run_command`（执行命令）、`run_skill_script`（跑脚本）前弹出确认卡。
- 卡上显示命令/文件路径，并可**展开查看完整内容/脚本预览**。
- **允许 / 拒绝**按钮；`Esc` 快速拒绝；120 秒不操作自动拒绝（显示"已过期"）；急停时显示「已急停 · 自动拒绝」。

## 5. 急停（最后一道人为刹车）

**触发：** 按配置的急停键（新安装默认 `F2` 与 `Ctrl+Shift+K`；本机若沿用旧配置可能仍是 `Esc`/`F2`）。网页内、地址栏、面板内都生效；**单键**（如 F2）在网页输入框打字时不触发（避免误伤网页编辑器），**组合键**始终有效。

**按下后发生什么：**
1. 中断正在执行的 AI 操作（页面加载、等待等立即结束）；
2. 终止由面板发起的外部 CLI 进程；
3. 拒绝所有待确认的权限卡；
4. 清空排队中的消息；
5. 底部横幅「AI 已急停挂起」，toast 显示计数（中断 N 个操作、终止 M 个进程、丢弃 K 条排队消息）；
6. 挂起状态**重启后仍保留**。

**恢复：** 在面板发一条消息，或点横幅上的「恢复」按钮（显示「AI 已恢复」提示）。

**配置急停键：** `⋯` 菜单 → 设置急停键 → 点录制框直接按键（或用虚拟键盘），最多 5 个；与浏览器快捷键冲突会被拒绝；提示"设置后该键会从网页中截获"。

## 6. 接入外部 AI 使用 Duplex

1. **Codex（MCP）**：面板 `✦` → 接入 Codex MCP（自动写入配置、失败自动回滚、原配置留备份）。
2. **Claude Code**：面板 `✦` → 复制接入命令到终端执行。
3. **MCP bridge（通用）**：`npm run bridge`（开发）或已安装版自带 bridge；MCP 客户端可调用 24 个工具：页面读取（snapshot/query/get_html/screenshot/get_console）、操作（click/type/hover/dblclick/drag/select_option/press/upload/scroll）、导航（navigate/search/history/new_tab/switch_tab/close_tab/list_tabs）、等待（wait）、高级（evaluate）、标注（annotation_mode）。浏览器未运行时 bridge 会自动拉起。

## 7. 模型配置（`⚙`）

- **新建**：一键预置 DeepSeek / OpenAI / 本地 Ollama（填写 Base URL、模型名、协议、认证）。
- **协议**：OpenAI 兼容 / Anthropic / OpenAI Responses / Gemini。
- **认证**：API Key，或「从本机 CLI 导入凭据」（Codex / opencode 登录态）；本地 Ollama 免 Key。
- **安全**：导入的凭据只允许发往官方域名；自定义网关必须勾选「我信任此网关」。
- **空闲超时**：推理类模型（思考久）建议调大（如 300 秒）。
- **切换**：点击配置行 → 再点一次确认切换（两步防误触）。
- **管理**：编辑、清除已保存的 Key、删除（连续确认）。

## 8. Skills

- `✦` → 导入文件夹（含 SKILL.md）；列表内启用/禁用、删除（两步确认）。
- 启用后的技能可在对话中被 AI 调用（读说明 → 跑脚本），脚本执行前有权限确认。

## 9. 数据与安全

- 数据目录 `~/.cobrowse/`：`settings.json`（设置/模型配置）、`browser-data.json`（书签/历史/下载记录）、agent 会话记录、`app.log`（日志）、`endpoint.json`（本地接口，供 bridge/插件连接）。
- 设置与数据均**原子写入 + 自动 .bak 备份**；损坏时自动回退备份，损坏原文件留档不丢。
- 已知上限（超出时静默清理，会话有提示）：历史 5000 条、AI 会话 50 个、单会话 200 条消息。
- 调试接口（`/api/debug/*`，可截 UI、执行 JS、合成键鼠）**仅开发构建可用**，打包版彻底关闭。

## 11. 已知边界与后续候选

- 标注在 Gmail/ChatGPT 这类"内部滚动容器"站点可能无法滚动页面（待实机确认修复）。
- 原生菜单（标签右键/搜索引擎/⋯/页面右键）个别交互需实机确认。
- 已调研的后续候选（未实现）：命令面板（统一搜标签/书签/历史/动作）、标签搜索、会话快照恢复、阅读模式、Glance 悬浮预览、标签固定、多选批量管理、书签 HTML 导入/导出。
