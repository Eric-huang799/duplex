# Duplex 新用户首跑体验评审：用 AI 做一个网页并导出

> **视角**：第一次用 Duplex 的普通用户。不看文档、不读源码，只依据界面完成"用 AI 做一个网页并导出"。
> **环境**：Windows / 150% 缩放；全新 profile（临时 `DUPLEX_DATA_DIR`，`electron` 用户目录为空），注入用户级 provider 配置（deepseek）。
> **成本控制**：全程只向模型发送 **1 条**请求。
> **时间**：2026-11-22 18:15 – 18:27。

---

## 一句话结论

**走通了，但最后两步是 AI 替我走对的，不是我学会的。**
一句话请求在 85 秒内产出了能看的落地页，并自动提交、自动导出；而"我"对设计画布的心智模型（这是什么、点哪、何时该提交、导出在哪）在 12 分钟里始终没建立起来——中途有 3 次以为界面坏了。

能独立完成（约 5 分钟拿到 zip），但**只在这条 happy path 上**：一旦需要自己插入资产、自己导出、自己撤销，就会卡住。

## 问题清单

### P0 — 走不通

#### P0-1 资产导入成功，但没有"插入画布"的路径
- **场景**：AI 面板 → `本地资产` → `+ 导入` → 选 `design-canvas.png` → 显示资产卡 → 想把它放进画布。
- **界面原文**：
  - 区块标题 `本地资产`，按钮 `+ 导入`，说明 `导入图片或文件，用于设计、分析或溯源`
  - 成功后：`design-canvas.png` / `2097×1200` / toast `已导入 1 个资产`
  - 资产卡上：**没有按钮、没有拖拽把手、没有"插入"字样、没有任何提示**
- **为什么别扭**：导入是成功的，但下一步完全空白。点资产（无反应）、双击（无反应）、拖到画布（无反应），导入前后画布上的 `data-did` 节点是同一批、数量没变，无 toast、无报错。用户只会得出一个结论："这功能坏了"。
- **建议**：资产卡 hover 出 `插入到画布`；点击默认插到当前视口中心并自动选中；支持拖拽落点；空状态写清"导入后可插入画布，或直接让 AI 使用"。

### P1 — 明显别扭

#### P1-1 最显眼的"开始设计"是画布里的一个元素，不是按钮
- **场景**：画布首屏，用户最可能点的蓝色 CTA。
- **界面原文**：页面 `和 AI 一起，把想法变成页面` + 按钮 `开始设计`；点击后右栏出现 `DATA-DID hero-cta`、`root / hero / hero-cta`、`由 system 创建（第 1 步）`、`frame 1440px`。
- **为什么别扭**：全屏最像"开始"的东西，结果是可编辑的示例组件。第一下就"误入开发者模式"，用户会怀疑点坏了、或以为自己进了调试界面。
- **建议**：示例页的 CTA 加"示例"角标；画布首屏覆盖一层真引导（让 AI 做一页 / 空白页 / 导入设计），并允许关闭。

#### P1-2 画布与检视器几乎全是开发者语言
- **场景**：画布工具栏、右栏、检视器、toast。
- **界面原文**：
  - 工具栏 title：`撤销（发送给宿主计算）`、`重做（发送给宿主计算）`、`提交这一轮的改动，并写一句话摘要`、`导出设计文档（由宿主处理）`
  - 右栏：`点击任意节点查看位置与尺寸`、`M — 放大镜（坐标 / data-did / 尺寸 / 颜色）`、`九点锚点 + 8px 网格吸附 + 数值微调`
  - 检视器：`DATA-DID`、`frame 1440px`、`由 system 创建（第 1 步）`、`相关约束 暂无`
  - 状态：`第 1 轮 · 有未提交改动`
- **为什么别扭**：新用户不知道"宿主"是什么、"轮"是什么、"提交"跟"保存"有什么区别；`data-did`、`frame`、"由 system 创建"直接把实现暴露给用户。
- **建议**：默认层用人话（位置 / 尺寸 / 文字 / 颜色 / 保存这一版），技术细节折叠到"高级"；toast 不出现"由宿主计算"这类内部状态。

#### P1-3 首屏最关键入口 `✦ 设计` 被挤成两行
- **场景**：首次打开工具栏。
- **界面原文**：按钮宽 32px，内容 `✦ 设计` 渲染为 `✦` + 换行的 `设 计`；同一行的 `✎ 标注` 宽 57px 正常。
- **为什么别扭**：看起来像 CSS 坏了，第一眼降低对产品的信任；而它恰恰是"做网页"最可能的入口。
- **建议**：与"标注"同宽；或只留 icon，把"设计画布"写进 tooltip。

#### P1-4 空对话没有告诉用户"我能做什么"
- **场景**：第一次打开 AI 面板。
- **界面原文**：空态只有居中一句 `和内置模型对话，它会直接操控这个浏览器`；输入框 `给内置模型下指令（Enter 发送）`；工具下拉里直接出现 `Gemini CLI（未检测到）`、`Qwen Code（未检测到）`、`＋ 添加自定义工具…`。
- **为什么别扭**：没有示例、没有"做网页"的暗示；"操控浏览器"听起来像高危操作，反而让人不敢发第一条；"未检测到"像调试面板。
- **建议**：空态给 3 个可点示例（"做一个产品落地页" / "把这张图放进页面" / "改配色"）；未安装的工具收进"更多"。

#### P1-5 导出不可发现，交付信息只活在聊天气泡里
- **场景**：想自己导出 / 导出后想打开或发送。
- **界面原文**：AI 面板设计卡片只有 `打开画布 / 撤销 / 提交`；画布工具栏 `导出`（`title="导出设计文档（由宿主处理）"`）；最终消息 `…导出包在 C:\Users\lenovo\Downloads\design-1-design-mwropbjd.zip（含 index.html + styles.css，可直接打开）。`
- **为什么别扭**：用户找不到"导出"按钮，只能靠 AI 主动做并记住路径；导出后没有"打开文件夹 / 预览 / 复制路径"；界面也没说"提交后才能导出"，更没提包里的网页在 `site/` 子目录、样式是相对路径（单独把 `index.html` 发出去会丢样式）。
- **建议**：导出后给一张结果卡（文件名、路径、`打开文件夹`、`预览页面`、`复制路径`），并提示"请发送整个文件夹"；设计卡片上直接放"导出"。

#### P1-6 运行中的红色"停止"与缺失的进度
- **场景**：AI 正在生成（85 秒）。
- **界面原文**：输入框下常驻 `停止`（红色实心）/ `暂停并修改` / `补充排队`。
- **为什么别扭**：红色按钮像"危险操作"，而用户不知道点它会不会丢掉已经生成的半页；同时没有进度条、没有"第几步/还要多久"，只有一串 JSON 工具卡在滚。
- **建议**：顶部进度条 + `生成中 · 3/6`；"停止"改成"取消生成"，并说明"已完成的部分会保留 / 会回滚到上一轮"；`暂停并修改`、`补充排队` 需要一句解释。

#### P1-7 撤销反馈不可信，且没有快捷键提示
- **场景**：想撤销一步改动。
- **界面原文**：点 `撤销` → toast `已请求撤销（由宿主计算）`；状态从 `第 5 轮 · 已提交` 变为 `第 6 轮 · 有未提交改动`；底部帮助只列 `M — 放大镜`、`Z — 整体缩放`、`R — 测量尺`、`定位`。
- **为什么别扭**："请求"意味着还没生效；画面看不出被撤销了什么；状态变成"有未提交改动"又像是我改了东西。没有 Ctrl+Z 提示，我不敢按（怕触发浏览器行为）。
- **建议**：撤销同步生效并短暂高亮变化的元素；toast 改为"已撤销上一步"；底部帮助补 `Ctrl+Z / Ctrl+Shift+Z`。

### P2 — 小摩擦
- 首屏没有一句话介绍 Duplex（只有标题 + 搜索框），看起来就是普通浏览器。
- `✎ 标注` 在新建标签页是灰的，原因只写在 tooltip：`当前页面不支持标注（仅普通网页可使用）`。
- 画布一进来就是 `第 1 轮 · 有未提交改动`（模板未提交），用户一进门就"背债"。
- 检视器的 `🔓 未锁定` 含义不明（锁定元素？锁定编辑？）。
- "轮"与"提交"强绑定，但界面没有解释"什么是一轮"。
- 工具卡把原始 JSON 当标题展示（`{"tabId":2,"fullPage":true}`、`{"ops":[{"op":"update"…`），对普通用户是噪音。
- 模型/授权入口藏在 `⚙`（`模型与授权`），里面是 `模型配置` / `站点权限` / `Skills 与 CLI 接入` / `AI 操作时间线`；**没有"信任模式"字样**，新用户不会把"站点权限"理解成"允许 AI 操作浏览器"。
- 导入走的是系统原生文件框（深色、非应用内），错误提示也是系统文案（`找不到文件。请检查文件名是否正确，然后重试。`），与应用风格割裂。

## 3 件做得好的地方

1. **一句话出成品，质量在线。** 85 秒、16 次工具调用、零确认弹窗，产出完整的 Lumen 落地页（薄荷/青碧配色、三栏等宽卡片、CTA 色块、页脚），并且给出结构与色值说明——这是"可交给同事看"的水平。
2. **过程透明且能自愈。** 每一步一张 ✓/✗ 卡片；失败那次直接写"插入顺序和旧模板冲突了，我先清空 root 再按顺序重建"，随后成功。用户能看到它在干什么、为什么重来，这比黑盒等待安心得多。
3. **画布本身是能用的。** 桌面/平板/手机断点、缩放、点选元素看位置尺寸、直接改文案、提交与导出在同一条工具栏——生成完之后，我确实可以在画布上继续改。

1. **画布首屏换成真引导**：三选一（让 AI 做一页 / 空白页 / 导入设计），示例页 CTA 加"示例"标记。一次解决"入口在哪 + 误点检视器"两个问题。
