# 站点兼容性回归清单（20 站）

> 用途：每次发版前跑一遍，记录 UA / 权限 / DRM / 弹窗 / 拦截 的实际表现。
> 这不是"测功能"，而是**发现"这个浏览器在真实站点上到底行不行"**——它同时是竞赛材料里"适配性验证"的原始数据。
>
> 记录格式：`日期 | 站点 | 场景 | 结果(通过/降级/失败) | 现象 | 关联功能`

## 二、每个站点记录什么

```
日期 | 站点 | 检查项 | 结果 | 现象描述 | 截图/日志
```

检查项固定五项，便于横向比较：

1. **加载**：首屏完成时间（粗略：< 3s / 3–8s / > 8s）
2. **登录**：能登录 / 需二次操作 / 失败（失败要写清是弹窗、内嵌 iframe 还是证书）
3. **核心动作**：该站最常用的一个动作是否能完成（看视频、下单、发消息、下载）
4. **权限**：有没有被问、问了之后能否正常工作
5. **AI**：`snapshot` 是否拿到合理结构；AI 点一下之后页面是否响应

## 四、执行节奏

- 每轮功能改动后：只跑与改动相关的 5 站（例如改拦截就跑 #5 #19 #20）
- 每次发版前：20 站全跑一遍，结果附在发布说明里
