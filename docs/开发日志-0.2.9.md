- 引入 `playwright-core`，连接 Electron 自带 Chromium，以 targetId 匹配内嵌标签，不下载额外浏览器。后台页取消节流，以支持定位与操作。

- 取消流程区分任务与标签；内置停止等待实际工具结束再开始替换指令；排队时保存标签，切会话删除旧自动发送；无问题标注在模型请求边界加入上下文。
- 标注使用来源标签、URL 与文档标识，采样前后校验；提交时捕获接收会话，拒绝过期页面和取消后的投递。
- 注入消息采用单条领取、60 秒租期及 20 秒续租、原 ID 重排和 ACK；OpenCode 消费者重连保持目标会话，急停清除已领取消息并暂停领取。
- 外部状态由主进程同步；面板卸载不关闭会话；Codex/Claude 新会话按结构化启动 ID 匹配，并保留后来发生的用户选择。本机 `codex exec --help`、`claude --help` 确认相应 stdout 选项，没有发起真实模型请求。
- 浏览器增加后台页与退出恢复；地址编辑、查找及错误重试使用来源标签；中文输入法确认不触发提交；待确认操作在浏览器顶部可见且不抢焦点。

### 明确的边界

- 滚动期间 DOM 事件不具备真实用户输入的 `isTrusted`；页面处理程序自身的导航/焦点/滚动副作用不能通用撤销。
- 在途 Playwright 动作有 200–250ms 的结束窗口，已发生的动作不能撤回；运行时等待它实际结束，避免新旧任务重叠。
- `evaluate` 的外部 API 回调逃逸、OpenCode 超出租期的确认失联与上游取消、直接 MCP 客户端缺少任务身份仍需 0.3.0 继续处理。详见交接文档。
