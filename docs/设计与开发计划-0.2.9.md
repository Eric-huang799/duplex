# Duplex 0.2.9 私有开发设计与实施计划

日期：2026-10-09。基线：3de1ed9，分支：codex/v0.2.9-private。

## 目标与范围

为 0.3.0 建立人机协作底座，修复任务页面、元素引用、输入焦点、标注、取消和会话投递的冲突；补充后台标签与浏览会话恢复。当前版本仅本地开发、提交和构建，不推送公开仓库，不创建发布标签或 Release。保留原有公开版本的历史和安装程序。

## 持续滚动方案

人工滚动只表示人在阅读，不暂停 AI 任务。记录近期人工滚轮与触摸滚动；AI 的读取继续运行，元素点击与标准输入在人工滚动期间使用 DOM 目标执行，不滚动页面、不抢输入焦点。不能用 DOM 等价完成的悬停、拖拽和坐标动作返回需要协调的明确结果，允许任务继续读取与推理。AI 主动滚动在人工阅读期间保留人的位置，并提示改用 snapshot/query/get_html 读取；不反复等待滚动停止。

用户已选择引入 Playwright 重做页面操作层。采用 playwright-core 连接 Electron 已有 Chromium，不下载第二套浏览器。普通模式使用 Playwright locator 的定位、可操作性等待和遮挡检查；人工滚动期间切换为 locator 对应的 DOM 元素操作。人点击、输入、导航或开启标注后，该标签的修改操作暂停，读取可以继续；显式恢复后重新观察页面。AI 合成输入需在执行上下文中标记，避免被当成人工接管。

## 协作与身份

- 每个调用方固定任务标签；内置任务在发送时捕获标签，MCP bridge 带稳定调用方身份。同页修改串行，不同标签可并行。
- 快照编号持续递增，旧引用不复用；页面替换后旧文档引用明确失效。动作之前校验引用对应元素仍连接且含义未变。
- 普通停止取消当前内置任务的工具和确认；急停取消全部。取消信号贯穿 CDP 操作，迟到结果和后台重试不能解除急停。
- 标注提交捕获来源标签、文档与接收会话，异步采样后复查取消状态；采样与投递不依赖新的活动标签。
- 注入消息保存目标会话；领取后保留未确认数据，失败只重排原消息，急停删除已领取消息，旧重试无法重新入队。
- 外部会话状态由主进程发布，面板新建成功进入续聊，启动完成不覆盖后来的模式选择。

## 验证与记录

重点场景：连续人工滚动期间 AI 读取和元素点击；动作期间改变焦点；标注期间 AI 点击；停止正在等待或输入的工具；批量投递部分失败；急停后旧消息重试；排队后切会话；新建外部会话后的第二轮续聊；后台页报错后重试；重启恢复研究标签。

命令：npm run typecheck；npx vitest run；npm run build；npm run build:bridge。实际输出与未覆盖边界记录在开发日志，避免重复执行相同检查。
