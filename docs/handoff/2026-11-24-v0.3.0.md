## 2. 0.3.0 交付了什么

### 2.1 设计画布 → 独立功能插件（推荐安装）

- 不再是浏览器硬编码入口；由功能宿主加载
- 内置、默认启用、设置页标记「推荐」
- 设置 → 功能插件可禁用/启用；禁用只隐藏入口（工具栏按钮、对话状态卡、agent/MCP 工具），**不删** `designs/` 数据
- 实测：禁用后入口消失、资产区保留；重新启用后恢复

### 2.2 通用功能插件宿主

- 内置插件 + 外部插件目录 `<cobrowseDir>/features/<id>/`
- 外部插件形态：`manifest.json` + `index.mjs`（activate/deactivate）
- 贡献点：工具栏按钮、agent 工具、对话状态卡
- 宿主负责：manifest 白名单校验、启停持久化、命令/工具路由、安装（复制 + 二次校验 + 失败回滚）、错误列表
- **外部插件在主进程执行，没有沙箱**——只安装可信来源

### 2.3 视觉：C + B

- 白天：Sand Studio 的暖卡片 + Quiet Graphite 的冷灰中性；主色赤陶 `#a06f58`
- 夜间：Quiet Graphite（`#141619 → #22262c`，提亮发丝线，石板蓝 `#8fa6bb`）
- 橙色反差色只用于关键动作：发送、模式选中、生成进度、功能按钮、资产插入提示、dirty 点
- 启动页插图 `start-bg.jpg` / `start-bg-dark.jpg` **未改动**，只换渐变/遮罩 token
- 画布页 `--ui-*` 同步同一套亮/暗 token

### 2.4 其他

- 本地资产库：内容寻址、剪贴板/文件夹导入、画布图片、导出自动打包 `site/assets`
- 新用户评审修复：空态示例、生成进度、工具卡人话标题、初始自动保存、导出结果卡、可编辑锁定文案等
- 多 agent 相关：共用标签仲裁、按 agent 隔离授权、会话级"一键放行"、急停恢复可见性

## 6. 已知限制与风险（按优先级）

1. **安装包未签名**：SmartScreen 警告；也没有 macOS/Linux 产物。要做正式分发，先接代码签名与 CI 打包。
2. **测试运行时和打包运行时不完全一致**：测试/开发跑 Electron `44.4.5`，安装包解析到 `44.11.5`；只做了启动冒烟，未在 44.11.5 上重跑全量测试。
3. **外部插件无沙箱**：`index.mjs` 在主进程执行，manifest 校验只保证结构合法。对外部插件应有信任提示/权限模型（尚未做）。
4. **MCP bridge 静态工具表**：`src/mcp-bridge/index.ts` 的 `tools/list` 仍来自静态 `toolDefs`；设计插件禁用时，经 bridge 的外部客户端可能仍看到 `design_*`（调用失败）。浏览器内 MCP 已按 `isToolAvailable` 过滤。
5. **插件生态能力缺口**：卸载/升级/签名/市场未实现；运行中手工丢进 `features/` 需重启扫描；manifest 名称/描述在启动时按语言生成，切语言需重启。
6. **自动更新未端到端验证**：`latest.yml` / blockmap 已上传，但没有真实升级测试。
7. **tag 与 HEAD 差一个 docs 提交**：`v0.3.0` 指 `d0ade30`；`3e85dec` 只改 README/发布说明，版本内容未变。
8. **UI 回归测试仍以脚本/截图为主**：没有 Playwright 全量 e2e；主题/插件的关键结论来自本轮真机与 CDP 检查。

## 7. 下一步建议

**P0（对外发布前）**

- 接代码签名（Windows Authenticode）并写入 CI；在干净机器上验证覆盖安装 + 升级
- 用打包版 Electron 重跑全量测试或至少核心 e2e
- 对安装包做一次真实 0.2.x → 0.3.0 覆盖升级验证

**P1（可扩展性与安全）**

- 外部插件信任模型：安装确认、权限清单（可访问哪些 API/目录），再考虑沙箱
- MCP bridge 改为动态工具列表（跟随 `isToolAvailable`）
- 插件卸载/升级；安装失败回滚已具备，可在此基础上扩展

**P2（体验）**

- 主题细节回归：对比度、设置页/弹窗/右键菜单等长尾界面
- 设计画布：工具卡展开后的原始参数仍显示 JSON（折叠态已人话）
- 视觉验收：补充亮/暗 × 关键界面截图矩阵，替换概念稿
